# Nan Jiang’s Engineering Portfolio

An English portfolio for an Electrical and Electronic Engineering student at the University of Nottingham Ningbo China. The site uses plain HTML and CSS and has no build step.

## Personalize

To add a public contact method, edit the footer in `index.html`. The circuit-board image is illustrative.

## Publish on GitHub Pages

1. Create a public repository. Name it `YOUR-USERNAME.github.io` for a personal site at that address, or choose a project name such as `portfolio`.
2. Extract this archive and commit its files to the repository root on the `main` branch. Keep `index.html` and the assets together. Include `.nojekyll`, which may be hidden in your file manager.
3. Go to **Settings → Pages**, set **Source** to **Deploy from a branch**, and choose **main** and **/ (root)**. Select **Save**.
4. After deployment, open the URL shown in **Settings → Pages**.

You can preview the site by opening `index.html` in a browser. The fonts fall back to system fonts if Google Fonts is unavailable.
